核心功能

写回答之前，可以先把这些事做了。

收到邀请、整理资料、判断哪些说法还要查证，都可以在桌面工作台里完成。

01

按擅长的领域挑题

同步知乎邀请和推荐，按领域、状态或标题筛选。应用根据问题标题与标签给出契合度，方便先看更贴近专长的题。

02

回到出处核对

联网查发布方原文、专业资料、媒体报道和公开讨论。写作台把引用编号和待核实事项放在正文旁边，审稿时可以点回原文。

03

先从资料原文提图

从已找到的资料提取图片，也能按具体画面搜索或导入本地图。候选图和正文分开管理，确认适用后再插入。

04

按平时的写法起稿

根据问题、资料和你的答题思路起草，再通读全文，重排需要调整的段落，合并重复说明。初稿可继续用 Markdown 编辑。

界面预览

从问题收件箱到写作台。

以下是软件实拍，点击截图可查看原尺寸。

问题收件箱

挑一道想答的题。

在列表里看最近收录的题，可以切换待阅、拟稿中、待批等状态，也能按领域找题。重点队列优先准备，其余题可以自己挑、自己决定什么时候写。

领域画像

让助手读一读旧文。

从历史回答与文章归纳专长和写作习惯，也会列出判断依据。想换一个主攻方向，可以修改领域关键词和权重；想少用某种表达，也能手动修订风格观察。

核查与批阅

还有哪句话需要查？

对照出处看日期、适用条件和原文措辞。助手会标记证据不足的说法，并显示核查进度；补查超时会保留已经保存的正文。

第一次使用

先拿一道熟悉的题试试。

  1. 登录知乎

    启动应用并登录。想补看此前的邀请，可以在问题收件箱点「同步近 3 天」。

  2. 配置模型

    在「设置 → 大模型」选择平台，填入自己的 API Key，再点「测试连接」。

  3. 打开写作台

    挑一道想答的题生成初稿。检查材料和配图，按自己的判断修改，再到知乎发布。

草稿保存在本机，助手不会代发。同步、检索和模型调用需要联网；拟稿所需的输入会发给所选模型服务。
