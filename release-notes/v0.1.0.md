我们推出**知乎答主助手 v0.1.0**。这是首个 Windows 版本，支持同步知乎邀请、按领域筛题、联网查证和提取原文配图。写作台会保留初稿、引用出处和待核实的说法，最后由答主在知乎手动发布。

## 具体更新内容

- 新增**问题收件箱**，支持同步知乎邀请和推荐、补拉最近 3 天的通知，以及按领域、契合度和处理状态找题。
- 新增**领域和文风画像**，从历史回答和文章归纳擅长的领域及不同题材的写法。可手动调整关键词、权重和风格观察，生成初稿时会参考对应的原文片段。
- 新增**资料来源库和分阶段核查**，按具体说法检索发布方原文、专业资料、媒体报道和公开讨论。引用编号可回查出处；拟稿前的查证与保存后的复核分开计时，每轮默认最多 3 分钟。
- 新增**原文提图和候选图库**。能从引用和核查网页提取配图，也可按具体画面搜索或导入本地图；加入备选图时不会改动正文。
- 加入 Markdown 编辑、预览、自动保存和发布后的本地归档。待批稿件可以保留备选图片、清空重拟；弃用的问题可以恢复到待解答。
- 加入托盘定时同步和活动统计，并提供带软件图标、品牌页眉和侧栏的 Windows x64 简体中文安装包。

## Bug 修复

- 修复近 3 天通知漏收，以及画像分析状态没有跟随本次任务更新的问题。
- 修复 Windows 安装版与旧版后台服务发生端口或数据目录冲突时，应用无法正常启动的问题。
- 修复正式构建中标题栏无法拖动、窗口按钮失效，以及部分知乎外链无法在系统浏览器打开的问题。
- 修复拟稿长时间无产出的问题。复核超时时会保留已保存的正文，之后可以继续核查。
- 修复跨语言检索容易漏掉原文和官方图片的问题。
- 修复核查来源标题过长时撑出侧栏的问题。相关来源结论相左时，会提示存在冲突并分别列出支持材料与反证。
